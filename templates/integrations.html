How to Get API Keys
GitHub Token
  1. Go to github.com → Settings
  2. Click Developer settings
  3. Select Personal access tokens → Tokens (classic)
  4. Generate new token with repo scope
  5. Copy and paste the token above
Slack Bot Token
  1. Go to api.slack.com/apps
  2. Create a new app → From scratch
  3. Add OAuth scopes: chat:write, channels:read
  4. Install app to your workspace
  5. Copy the Bot User OAuth Token (starts with xoxb-)
Jira API Token
  1. Go to id.atlassian.com/manage-profile/security
  2. Click Create and manage API tokens
  3. Click Create API token
  4. Name it "KnowBridge AI" and copy
  5. Use your Atlassian email + this token above
